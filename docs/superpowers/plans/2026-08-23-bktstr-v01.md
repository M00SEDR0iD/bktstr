# BKTSTR v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Railway-hosted, read-only granular equity backtester that can be invoked remotely.

**Architecture:** A standard-library HTTP service delegates request validation to `service.py`, market data to provider adapters, rule evaluation to `rules.py`, and causal trade simulation to `engine.py`. Railway deploys the repository using the included Dockerfile.

**Tech Stack:** Python 3.12, pandas, httpx, pytest, Railway.

**Spec:** `docs/superpowers/specs/2026-08-23-bktstr-design.md`

## Global Constraints
- Read-only; no brokerage writes.
- Signal on bar close and entry on next bar open.
- Adverse slippage.
- Stop-first for ambiguous stop/target OHLC bars.
- Maximum requested date span 730 days.
